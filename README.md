# Border Risk Zone Prediction using Machine Learning

## Project Overview
This project predicts border risk zones using machine learning and visualizes results using Power BI. An AI chatbot is also developed for interactive risk prediction.

## Features
- Data preprocessing and analysis
- Risk classification (Low, Medium, High)
- Decision Tree Machine Learning model
- Power BI dashboard visualization
- AI chatbot using Dialogflow

## Tools Used
- Python (Pandas, Scikit-learn)
- Power BI
- Dialogflow

## Results
- Achieved ~86% accuracy
- Identified high-risk zones
- Interactive dashboard for decision support
